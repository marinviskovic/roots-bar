# Roots, verzija bez Lovablea

Ista stranica kao Lovable projekt "Roots Bar Showcase", napisana ispočetka u Reactu, Tailwindu i Viteu.

- `npm install`, pa `npm run dev` za razvoj, `npm run build` za gotovu stranicu u `dist/` (statične datoteke, mogu na bilo koji hosting).
- Fotografije idu u `src/assets/` s istim imenima kao u Lovable projektu (popis u `src/data/cocktails.ts`, `hero.tsx`, `atmosphere-section.tsx`, `story-section.tsx`).
